# Hangman Game

A simple command-line Hangman game written in Python.

## Features

- Randomly selects a word from a built-in word list
- Allows up to 6 incorrect guesses
- Validates each guess
- Detects repeated guesses
- Supports replaying the game

## Requirements

- Python 3.8 or newer

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/hifzayasmeen/Hangman.git
   cd Hangman
   ```

2. Start the game:

   ```bash
   python task1_hangman.py
   ```

## How to Play

1. Enter one letter when prompted.
2. Correct guesses reveal letters in the hidden word.
3. Incorrect guesses reduce the remaining attempts.
4. Guess the complete word before reaching 6 incorrect guesses.
5. Choose `y` when asked to play another round.
